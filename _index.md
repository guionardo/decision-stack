# Catálogo de Tecnologias

Índice de tecnologias avaliadas para reuso no planejamento de novas aplicações. Cada registro documenta o que a tecnologia faz, os problemas que resolve e pontos de atenção — material de decisão para escolher sem reescrever.

## Como usar

- **Registrar**: peça ao Hermes `registrar tecnologia <URL oficial>` (skill `registrar-tecnologia`).
- **Consultar**: pergunte `que tecnologia resolve <problema>?` (skill `consultar-tecnologias`).
- Cada documento vive na subpasta da sua categoria e segue o [[_template]].
- Busca no Obsidian: tag `#catalogo` + tags de categoria (ex.: `#backend`, `#database`).

## Categorias

| Pasta | Escopo |
|---|---|
| `Backend/` | Frameworks web, APIs, runtimes server-side |
| `Frontend/` | Frameworks UI, bibliotecas client-side, CSS |
| `Databases/` | SQL, NoSQL, cache, search, vetoriais |
| `Infra/` | Cloud, containers, orquestração, IaC, storage, rede |
| `AI-ML/` | LLMs, frameworks de ML, agentes, RAG, visão |
| `DevOps/` | CI/CD, git, feature flags, release |
| `Security/` | AuthN/AuthZ, secrets, criptografia |
| `Messaging/` | Filas, event streaming, pub/sub, e-mail |
| `Observability/` | Logs, métricas, tracing, dashboards |
| `Testing/` | Unit, integração, e2e, carga, mocks |
| `Linguagens/` | Linguagens e toolchains |
| `Mobile/` | iOS, Android, cross-platform |
| `Ferramentas/` | Dev tools, CLI, produtividade, docs |
